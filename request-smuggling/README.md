# Request smuggling

Probes that check Kidlat and a front proxy agree on where every request ends.

## How it works

Each probe is a `POST /probe` whose body hides `GET /smuggled`, using a framing trick. After each probe, a victim `GET /victim` is sent on a fresh connection. The app runs in-process and records every request Kidlat actually executes.

39 probes:

- **CL.TE and TE.CL** across 13 `Transfer-Encoding` variants: `chunked`, `xchunked`, space before colon, tab, duplicated headers (both orders), `chunked, identity`, `identity, chunked`, obs-fold, `CHUNKED`, `"chunked"`, bare LF before the header, leading space.
- **Content-Length:** conflicting duplicates, `+N`, `N, N`, hex, space before colon.
- **Line endings and bytes:** bare LF, bare CR, NUL in a header value.
- **Chunked bodies:** HTTP/1.0 with chunked, chunk size overflow, trailing junk after the size, chunk extension with bare LF, chunk data without CRLF.

The probes run twice:

- **Direct** to Kidlat.
- **Through nginx** ([`nginx.conf`](nginx.conf)) with upstream keep-alive. A desync would leave a poisoned upstream connection, and the victim would get someone else's response.

## Pass criteria

For every probe:

- Kidlat never executes `/smuggled`.
- The victim gets `200` with its own body (`path=/victim`).

## Run

Direct:

```bash
npm run smuggling
```

Through nginx (Linux, Docker):

```bash
docker run -d --name nginx --network host -v "$PWD/request-smuggling/nginx.conf:/etc/nginx/nginx.conf:ro" nginx:1.27-alpine
```

```bash
npm run smuggling:nginx
```

The proxy mode takes `--via <host:port>` and `--app-port <port>`, so another proxy can be tested the same way.

## Output

- [`results/request-smuggling.json`](../results/request-smuggling.json) (direct) and `results/request-smuggling-nginx.json`: each probe's first response line, the requests Kidlat executed, and the verdict.
- In CI, a Markdown table of every probe is added to the job summary.

## Limitations

Only nginx 1.27 is tested as a front proxy. HAProxy, Envoy and CDNs may frame requests differently.
