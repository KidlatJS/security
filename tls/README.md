# TLS

A [testssl.sh](https://testssl.sh) scan of Kidlat's native TLS.

## How it works

1. [`server.mjs`](server.mjs) creates a fresh RSA test PKI with `openssl`: a root, an intermediate, and a leaf for `127.0.0.1`, valid for 397 days ([`lib/tls-chain.mjs`](../lib/tls-chain.mjs)).
2. Kidlat serves the leaf and intermediate on port 8443, and writes the root to `build/testssl/root.pem`.
3. testssl.sh 3.2 scans the server with `--add-ca root.pem`. Because it trusts the test root, the grade reflects Kidlat's TLS configuration rather than "unknown CA".
4. [`check-testssl.mjs`](check-testssl.mjs) checks the JSON report.

## Pass criteria

- Overall grade **A** or better.
- No HIGH or CRITICAL findings.
- MEDIUM findings are reported but don't fail the scan.
- Findings about the test certificates themselves are ignored: `cert_*`, `intermediate_cert_*`, OCSP, CAA, and scanner problems.

## Run

Requires Docker and `openssl`. Start the server:

```bash
mkdir -p build/testssl && npm run tls:server
```

In a second terminal, run the scan:

```bash
docker run --rm --network host -v "$PWD/build/testssl:/out" drwetter/testssl.sh:3.2 --quiet --color 0 --warnings off --add-ca /out/root.pem --jsonfile /out/result.json https://127.0.0.1:8443
```

Then check the result:

```bash
npm run tls:check
```

`--network host` needs Linux. The test certificate only covers `127.0.0.1`, so run the scan where it can reach that address.

## Output

- [`results/tls.json`](../results/tls.json): grade, grade-cap reasons, and every MEDIUM or higher finding.
- In CI, the raw testssl report (`build/testssl/result.json`) is uploaded as an artifact, and a findings table is added to the job summary.

## Limitations

Because it's a test PKI, real-world certificate issuance, OCSP stapling and CAA records are not graded.
